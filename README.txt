LIANABRIELE'S BIRTHDAY CARD

OPEN THE CARD
Double-click index.html to open the card in a browser. The photos are included
in the images folder. Display fonts and the birthday song load from external
services when connected to the internet; the card and photos work offline.

CHANGE THE PHOTOS OR CAPTIONS
Replace a photo in the images folder using the same filename, or edit the
birthdayPhotos list in script.js to change a photo's filename, description,
or caption. The featured photo starts on the seventh entry.

CHANGE THE COLORS OR LAYOUT
Edit the color values near the top of styles.css. The rest of that file
controls the page layout and responsive styles.

DEPLOY TO VERCEL
Import this Git repository in Vercel as a static site. Leave the framework
preset as "Other" and leave the build command and output directory empty;
index.html, styles.css, script.js, and images/ are served from the repository
root. Vercel will deploy new commits pushed to the connected branch.

FILES
index.html — birthday card structure and messages
styles.css — colors, typography, and layout
script.js — photo carousel, birthday wish, and music control
images/ — eight birthday photos
